# EmbeddedDriverDevelopment
STM32 Bare-Metal Driver Development (MCU1)

A hands-on embedded systems project repository based on the Udemy course:

“**Mastering Microcontroller and Embedded Driver Development (MCU1)**”

This repository focuses on learning **bare-metal driver development using Embedded C** by building peripheral drivers for STM32 microcontrollers completely from scratch without relying on HAL libraries.

# 🚀 What This Repository Covers

This project demonstrates low-level embedded firmware development for STM32 microcontrollers including:

* GPIO Driver Development
* SPI Driver Development
* I2C Driver Development
* USART/UART Driver Development
* RCC (Reset and Clock Control)
* Interrupt Handling
* NVIC Configuration
* Peripheral Register Programming
* Clock Configuration
* Bitwise Register Manipulation
* Bare-Metal Embedded C Programming


# 🎯**Learning Objectives**  

By working through these projects, I learned how to:  
* Understand STM32 architecture  
* Read STM32 reference manuals and datasheets  
* Develop reusable peripheral drivers  
* Configure peripheral registers directly  
* Implement interrupt-driven communication  
* Build hardware abstraction layers from scratch  
* Debug embedded firmware effectively  
* Write modular and scalable embedded code

# 🛠️**Technologies Used**  
* Embedded C  
* STM32F103xx Microcontroller  
* STM32 Nucleo Board  
* STM32CubeIDE  
* ARM Cortex-M Architecture  
* CMSIS  
* Bare-Metal Programming
